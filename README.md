# Basta Masarap Restaurant

A simple Filipino restaurant website built with **PHP, MySQL, HTML, CSS, and JavaScript**. Originally made as a school project to practice building a database driven website with users, dishes, orders, reviews, ratings, and basic restaurant functionality. Ngayon, mini repolish na lang siya para hindi mukhang fossilized school project sa GitHub.

**Project Status:** MINI REVAMP / SCHOOL PROJECT

### What This Shit Can Do

Basta Masarap lets users **browse Filipino dishes, view food details, place orders, manage favorites and wishlist items, leave ratings and comments, manage their account, and view their orders**. May basic restaurant flow din from browsing the menu to actually placing an order.

### Admin Side

May basic **Admin Dashboard** for managing the restaurant data, including users, dishes, orders, reviews, ratings, comments, deliveries, and other necessary information.

Hindi ito enterprise restaurant software. Simple project lang siya na ginawa para matuto, mag experiment, at magkaroon ng isa pang PHP application sa GitHub graveyard.

### Tech Stack

**PHP, MySQL, HTML, CSS, JavaScript, and XAMPP.**

PHP handles the backend logic, MySQL handles the database, while HTML, CSS, and JavaScript handle the frontend and interactions.

### About

This started as a **school project** focused on learning basic web development, database operations, CRUD, user management, and restaurant workflows.

Instead of completely rebuilding the whole thing, this version keeps the original idea and gives it a simple polish.

Old project. New coat of paint.

Still fucking Basta Masarap.
